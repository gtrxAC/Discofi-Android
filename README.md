# Microcord-Android
Microcord-Android is a new Discord client for legacy Android devices, based on [Microcord](https://github.com/gtrxAC/Microcord).

(to be integrated to the base repository in the future)

## Status
### Working
* Main menu with servers and DMs
* Channel list
* Chat screen with pagination
* Password and token login
* Sending messages
* Message timestamps
* Viewing replies, attachments (images and videos with previews, files with a filename/size row) and embeds
* Opening attachments in the browser

### Planned for first release
* Sending attachments
* Sending replies
* Message editing/deleting
* Token file import
* HTTP connection over BlueWAP

### Not implemented
* Emojis, reactions
* Gateway
* etc.
